# Sample Agent Instructions

## Purpose
Provide a clear, concise set of instructions for running and interacting with the sample agents in this workspace.

## Quick Start
- Identify the app you want to run (Express, Flask, React/Vite, or static webapp).
- Install dependencies (if required).
- Start the app with its documented command.

## Usage Guidelines
- Keep instructions concise and actionable.
- Follow existing project conventions and scripts.
- Prefer documented scripts in package.json or requirements.txt.
- When starting servers, use non-blocking commands if running in automation.

## Notes
- Update this file when new sample apps are added.
- If an app has no explicit script, document the expected entry point.
