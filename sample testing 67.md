# Sample Testing 67

A collection of sample web applications built for testing and demonstration purposes. This repository includes vanilla JavaScript projects, a React app, and a simple landing page.

---

## Repository Structure

```
sample-testing/
├── my-react-app/       # React 19 application powered by Vite
├── simple-webapp/      # Vanilla HTML/CSS/JS web application
├── todo-app/           # Interactive To-Do list application
├── landing-page/       # Simple frontend landing page
├── rama.txt            # Text content file
└── sample testing 67.md  # This README
```

---

## Projects

### 1. `my-react-app`
A React application scaffolded with [Vite](https://vitejs.dev/).

- **Stack:** React 19, Vite 5
- **Scripts:**
  ```bash
  npm install       # Install dependencies
  npm run dev       # Start development server
  npm run build     # Build for production
  npm run preview   # Preview production build
  ```

---

### 2. `simple-webapp`
A minimal vanilla web application — great as a starting point or boilerplate.

- **Stack:** HTML, CSS, JavaScript (no dependencies)
- **How to run:** Open `index.html` directly in any browser.

---

### 3. `todo-app`
A lightweight, interactive To-Do list application built with plain JavaScript.

- **Features:**
  - Add new tasks via input field
  - Delete individual tasks with the `x` button
- **Stack:** HTML, CSS, Vanilla JavaScript (no dependencies)
- **How to run:** Open `index.html` directly in any browser.

---

### 4. `landing-page`
A clean frontend landing page with a welcome card and interactive button.

- **Features:**
  - Welcome card UI
  - Click counter button
- **Stack:** HTML, CSS, Vanilla JavaScript (no dependencies)
- **How to run:** Open `index.html` directly in any browser.

---

## Getting Started

1. **Clone the repository**
   ```bash
   git clone <repository-url>
   cd sample-testing
   ```

2. **For the React app**, navigate into the directory and install dependencies:
   ```bash
   cd my-react-app
   npm install
   npm run dev
   ```

3. **For all other apps**, simply open their respective `index.html` file in a browser — no installation required.
